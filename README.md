## 📋 Course Overview

This course introduces students to the fundamentals and advanced concepts of modern web technologies. Students build practical skills in front-end and back-end development, covering standards-based HTML/CSS, interactive JavaScript, responsive design, and server-side scripting.

By the end of the semester, students will be able to **design and deploy full-stack web applications**.

## 🧭 Topics Covered

| # | Area | Topics |
|:-:|---|---|
| 1 | **Web Fundamentals** | Client/server and three-tier architecture, the Internet vs the Web, URIs, HTTP requests, responses, and status codes |
| 2 | **HTML** | Elements, attributes, page structure, forms and input types, XML, XHTML, DOM, DHTML |
| 3 | **CSS** | Selectors, inserting CSS, the box model, borders, margins, padding, positioning, layouts |
| 4 | **JavaScript** | Variables, data types, operators, control flow, functions, events, arrays, objects |
| 5 | **HTML DOM** | Finding and changing elements, changing CSS, form validation, debugging |
| 6 | **Server Side** | PHP, MySQL, and building full-stack web applications |

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/RRudro/WebTech_Fall-2026-27.git

# 2. Move into the folder
cd WebTech_Fall-2026-27

# 3. Open it in VS Code
code .
```

For PHP examples, copy the project into the XAMPP `htdocs` folder, start **Apache** (and **MySQL** if needed) from the XAMPP Control Panel, and open `http://localhost/<folder-name>` in your browser.

## 📤 Lab Submission Workflow

1. **Create** a GitHub account.
2. **Create** your own Web Technologies repository and submit its link in the first lab.
3. **Push** every lab task and assignment to that repository.
4. **Deploy** your application where possible (for example, GitHub Pages for front-end work).

```bash
git add .
git commit -m "Lab 01: registration page"
git push origin main
```
